Apache Superset

Version 4.0.0rc1
Release Candidate 1
🎉 Major Release Highlights

Superset 4.0.0rc1 introduces significant improvements in performance, security, and user experience. This release candidate brings enhanced chart capabilities, improved data source management, and a more intuitive interface.

🚀 New Features

  • Enhanced Chart Library: New chart types including advanced analytics visualizations and improved interactivity
  • Improved Data Source Management: Better support for multiple database types and enhanced connection pooling
  • Advanced Security Features: Row-level security improvements and enhanced role-based access control
  • Performance Optimizations: Faster dashboard loading and improved query performance
  • Modern UI Components: Redesigned interface with better accessibility and responsive design

🔧 Improvements

  • SQL Lab Enhancements: Better query editor with improved syntax highlighting and autocomplete
  • Dashboard Builder: More intuitive drag-and-drop interface and enhanced customization options
  • Data Exploration: Improved filtering and drill-down capabilities
  • Export Functionality: Enhanced export options for charts and dashboards
  • Mobile Experience: Better responsive design for mobile and tablet devices

🐛 Bug Fixes

  • Fixed dashboard refresh issues in certain browser configurations
  • Resolved chart rendering problems with large datasets
  • Fixed authentication issues in specific deployment scenarios
  • Corrected data type handling for various database connectors
  • Resolved performance issues with complex queries

⚠️ Breaking Changes

  • Database Connection Changes: Some database connector configurations may need updates
  • API Endpoints: Several REST API endpoints have been updated or deprecated
  • Configuration Options: Some configuration parameters have been renamed or restructured
  • Plugin System: Custom plugins may require updates for compatibility
⚠️ Important Notes

This is a release candidate version. Please test thoroughly in non-production environments before deploying to production. Some features may still have bugs or incomplete functionality.

📋 Installation & Upgrade

To install Superset 4.0.0rc1:

pip install apache-superset==4.0.0rc1

For existing installations, upgrade using:

pip install --upgrade apache-superset==4.0.0rc1

After installation, run database migrations:

superset db upgrade
